# Blog Post Writing Guidelines

This document outlines the strict requirements and formatting standards for all blog posts generated for Bharat Medical Hall.

## 1. Content Requirements
- **Length:** Every blog post must be detailed, comprehensive, and **at least 1000 words** in length.
- **Tone:** Professional, empathetic, medical, and authoritative.

## 2. SEO Optimization (AEO, GEO, SERP)
- **AEO (Answer Engine Optimization):** Ensure the article directly answers user queries in a clear, concise manner (e.g., using bullet points, direct answer paragraphs under headings).
- **GEO (Generative Engine Optimization):** Structure the content with clear H2 and H3 headings so AI overviews and LLMs can easily parse the core concepts. Use natural language that reads conversationally yet professionally.
- **SERP (Search Engine Results Page):** Use a compelling Title tag and Meta Description. Use a prominent, H1 tag for the main title.

## 3. Calls to Action (CTAs)
- **Mid-Blog CTA:** Every article MUST include a mid-blog Call to Action encouraging users to "Talk with an Expert". It should be a prominently styled block linking to the WhatsApp contact or the contact page.
- **Bottom CTA:** The standard sidebar and footer CTAs (already built into the PHP template) should be maintained.

## 4. Internal Linking
- **Rich Internal Links:** Naturally weave in links to other relevant blog posts (e.g., `/blog/how-long-should-i-take-milk-thistle-to-detox-liver.php`) and specific product pages (`/products/glucose-one-machine/`).
- Use descriptive anchor text, not "click here".

## 5. Schema Markup (JSON-LD)
Every blog post must include the following schema types in the `<head>` or at the top of the content:
- **Article Schema:** Defining the headline, author, and publisher.
- **MedicalWebPage Schema:** For medical authority.
- **FAQPage Schema:** Include at least **6-7 detailed Frequently Asked Questions** related to the topic.
- **BreadcrumbList Schema:** For better site navigation tracking in search engines.

*Note: Always review this file before generating a new blog post to ensure compliance.*
